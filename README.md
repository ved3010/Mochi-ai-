## 🌟 Overview

**Mochi AI** is a lightweight, floating desktop AI companion designed specifically for busy college students and developers. Unlike rigid chatbots trapped in browser tabs, Mochi lives natively on your desktop with delightful organic squish-and-stretch physics, expressive facial animations, and real-time proactive intelligence.

Whether you choose **🫧 Mochi** (the squishy cute blob) or **🐱 Kittu** (the warm desktop cat), your companion watches your back throughout your work session:
- **Syncs assignments** directly from Google Classroom with overdue urgency alerts.
- **Scans Gmail** for urgent college circulars, exam notifications, and internship updates.
- **Tracks upcoming schedules** via Google Calendar.
- **Discovers career opportunities** and live hackathons on Unstop.
- **Synthesizes your entire day** into a realistic, time-blocked Pomodoro sprint plan with one command: `plan my day`.
- **Protects your flow state** by silently detecting when you're coding, watching lectures, or taking quizzes so it never disturbs you.

## ✨ Key Features

### 1. 🫧 Adorable Multi-Companion Engine (Mochi & Kittu)
- **Instant Character Switcher**: Toggle seamlessly between **🫧 Mochi** (squishy blob) and **🐱 Cat** (Kittu) right from the floating HUD.
- **Pure Vector SVG Art**: Beautiful crisp rendering at any screen resolution or DPI with zero raster pixelation.
- **Squishy Physics & Dynamic Gestures**: Bouncy squash-and-stretch drag physics, gentle floating hover animations, keyboard typing movements, and scroll unrolling.
- **Dynamic Face Expressions**: Randomly cycles through adorable moods over time:
  - 😄 Happy Cheerful
  - 😉 Playful Wink
  - ✨ Star-Eyed Excited
  - 😴 Sleepy Rest
  - 🥺 Shy Blushing

### 2. 🎵 Ambient & Custom Sound Effects
- **Character Audio Identity**:
  - Mochi: Cheerful squeaks, gentle purrs, and soft chime notifications.
  - Kittu: Classic cozy meows and purring.
- **Hover Audio Selector**: Right-click to customize Mochi's ambient hover soundscape:
  - ✨ **Fairy Shimmer** (default) — Celestial music-box sparkle arpeggio
  - 🫧 **Soft Bubbles** — Gentle, organic water-drop pops
  - 🎶 **Music Box** — Calming music box notes
  - 🐾 **Playful Squeak** — Cute squeaky bounce
  - 🔇 **Silent** — Zero distraction

### 3. 🎯 Unified Daily Workflow Planner (`"plan my day"`)
Say or type `"plan my day"` to receive a clean, time-blocked action plan generated by Gemini:
1. **High-Priority & Urgent Deadlines** — Top overdue or upcoming assignments with specific course titles.
2. **Systematic Daily Sprint** — 25–45 min Pomodoro blocks tailored to your study load.
3. **Career & Growth Target** — 1 top curated active hackathon or competition from Unstop.
4. **Mochi's Tip & Energy Check** — Friendly, warm motivation reminding you to stay hydrated and take rests.

### 4. 📋 Interactive Priority To-Do List
- **On-Demand Intelligence**: Stays tucked away until you explicitly ask for your tasks (`"tasks"`, `"show my tasks"`, `"todo"`).
- **Four Urgency Tiers**: Filter instantly by `Urgent`, `High`, `Medium`, and `Low`.
- **One-Click Priority Cycling**: Click any priority badge on a task to cycle its urgency.
- **Persistent Local Storage**: Tasks persist across sessions with safe Electron storage.

### 5. 🎙️ Voice Interaction & Groq Whisper
- **Push-to-Talk & Floating Mic**: Click the glowing mic icon or speak directly.
- **Groq Whisper Fast STT**: Cloud-accelerated, near-instantaneous transcription without lagging your machine.
- **Hands-Free Convenience**: Ask questions, check deadlines, or control playback without leaving your editor.

### 6. 🛡️ Intelligent Stuck Detector & Focus Shield
- **Non-Disturb Zones**: Automatically detects when you are active on coding platforms (LeetCode, HackerRank, IDEs) or watching video lectures (YouTube, Coursera, NPTEL) and **never interrupts**.
- **Gentle Check-In**: If you have been idle or inactive on a work application for too long, Mochi gently offers assistance without being intrusive.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher)
- **macOS** or **Windows** (transparent frameless window supported on both)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ved3010/Mochi-ai-.git
   cd Mochi-ai-
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables** (Optional but recommended):
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your keys:
   ```ini
   # Groq Whisper API (for voice STT)
   GROQ_API_KEY=gsk_...

   # Google Gemini API (for AI reasoning & workflow planning)
   GEMINI_API_KEY=AIzaSy...

   # Google OAuth Credentials (for Classroom, Gmail & Calendar sync)
   GOOGLE_CLIENT_ID=your_oauth_client_id.apps.googleusercontent.com
   GOOGLE_CLIENT_SECRET=your_oauth_client_secret
   ```

4. **Launch Mochi**:
   ```bash
   npm start
   ```

## 💬 Fast Commands & Shortcuts

You can type these into Mochi's search bar or speak them via voice:

| Command | Action |
| --- | --- |
| `plan my day` | Generate a full Pomodoro daily sprint from Classroom, Gmail & Calendar |
| `tasks` / `list tasks` | Open the interactive Priority To-Do List |
| `add task: Complete OS Lab` | Add a new task to your list |
| `classroom assignments` | Show all pending Google Classroom coursework |
| `check gmail` | Scan inbox for urgent college or career notices |
| `check calendar` | Show today's upcoming meetings and lectures |
| `find hackathons` | Fetch active live hackathons and coding challenges from Unstop |
| `open Unstop` | Open the Unstop student portal in your default browser |
| `play lofi on Spotify` | Search & open lofi focus beats in desktop Spotify |
| `help` | Display quick commands and tips |
